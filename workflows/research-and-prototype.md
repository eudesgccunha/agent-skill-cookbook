# Research and prototyping

- **Facts from docs or APIs:** run `research`. It reads primary sources and saves a Markdown file in the repo.
- **"Does this design feel right?":** run `prototype`. Build a throwaway, answer the question, then delete it.
- **Human-only steps** (credentials, dashboards, cutovers): run `wizard` to generate an interactive bash script.

Keep research output in the repo only if the team will reuse it.
