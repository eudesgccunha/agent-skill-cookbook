# Review and PR

1. **Review.** Run `code-review` (or Superpowers `requesting-code-review`) against the base branch. It checks repo standards and the original spec, side by side.
2. **Fix findings** or note why you skip them. Use `receiving-code-review` to verify feedback before applying it.
3. **Write the PR body** with `pr`.
4. **Commit messages.** `caveman-commit` gives compact Conventional Commits.

Write commit and PR text in normal prose. Caveman style stays out of anything other people read.
